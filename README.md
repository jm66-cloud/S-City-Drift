# S市漂模拟 v1.0

像素风电脑桌面模拟经营游戏。灵感来自《不要喂猴子》，融合 A 股模拟交易、公司经营、恋爱养成、犯罪冒险等元素。

## 快速开始

直接用浏览器打开 `index.html`，或通过 Jekyll 部署到 GitHub Pages。

## 游戏说明

- 你是刚来到申海市的年轻人，通过炒股改变命运
- 24 现实分钟 = 1 个游戏日，8:00-18:00 为交易时段
- 需要平衡日常生活（吃饭、睡觉、压力）与股票交易
- 积累资本后买房买车，创办公司，最终 IPO 上市
- 5 种胜利结局 + 4 种失败结局
- 支持简单/普通/困难三档难度

## 技术栈

纯 HTML/CSS/JavaScript 单页应用，无外部依赖。
- 像素风 CRT 显示器界面
- delta-time 增量游戏引擎
- localStorage + IndexedDB 双存储
- 150 支模拟股票 + 20 个 AI 交易机器人
- Canvas 像素风 K 线图
