# 申海漂 — 开发计划

> 基于现有素材 + 策划案优先级，采用「先跑通核心玩法，再填充内容」的策略。
> 素材策略：现有素材全用，不够的复制/改色/纯色块占位，后期替换。

## 素材使用总览

| 素材 | 用途 | 处理方式 |
|------|------|----------|
| `roguelikeCity.png` | 城市地图瓦片 | 16×16 → Phaser 放大 4 倍到 64×64 |
| `interiors.png` | 室内瓦片 + 家具 | 48×48 → Phaser 放大 1.33 倍到 64×64 |
| `roomBuilder.png` | 房间结构（门窗/楼梯） | 同上 |
| `adam/alex/amelia/bob.png` | 玩家 + 核心 NPC | 16×16 → 放大 3 倍到 48×48，补帧到 48×64 |
| `topDown_walk/idle.png` | 路人 NPC | ~26×26 → 放大 2 倍，改色区分 |
| `sBlueCar.png` 等 6 辆 | 城市车辆装饰 | 直接使用 |
| `genericItem_color_*.png` | 物品图标 | 163 个，缩放适配 32×32 背包格 |
| `Yellow` 主题 UI | 全部游戏 UI | 按钮/图标/箭头/滑块/输入框/复选框 |
| `Kenney Future` 字体 | 游戏全部文字 | CSS `@font-face` 加载 |
| `assets/sounds/*.ogg` | UI 交互音效 | 直接使用 |
| `sounds/*.mp3` | 场景 BGM | 按情绪键引用 |
| 纯色块 + 文字 | 所有缺失素材的占位 | Phaser Graphics / CSS |

## 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 素材风格不统一 | 画面割裂 | 开发期接受，后期统一替换为像素风 |
| 室内场景 20 个太多 | 开发周期长 | P0 先做 3 个，P1 做 4 个，P2 逐步填充 |
| 炒股系统复杂 | 核心玩法延期 | 阶段 1 先做最简单的买卖，K 线后期加 |
| NPC 日程系统 | AI 逻辑复杂 | 先用固定位置站立，后期加移动 |
| Electron 打包问题 | 发布延期 | 先保证 Web 版可玩，Electron 后期适配 |
