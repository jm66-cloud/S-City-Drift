## III. 角色清单 (Character Sprites)

### 玩家角色 — sprites/characters/player/
- 6套服装变体 (男装A/B, 女装A/B, 中性A/B)
- 5种发型, 6种发色
- 4方向: 下/左/右/上
- 每方向: idle(2帧) + walk(4帧) + interact(2帧) = 8帧/方向
- 每角色: 32帧/套
- 文件格式: spritesheet 4×8 网格, 48×64/帧
